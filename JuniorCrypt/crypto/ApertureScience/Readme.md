# Aperture Science: Stream Calibration — Writeup

**Category:** Crypto
**Flag format:** `grodno{...}`

## Challenge Description

> Following the opening of formal proceedings related to Aperture Science, investigators получили limited access to surviving fragments of the facility's internal systems. One of the first recovered artifacts came from a calibration subsystem and appears to reference materials associated with GLaDOS.

We're given two files:

- `ciphertext.txt` — a hex-encoded ciphertext
- `encoder.py` — the encryption source code

**encoder.py**
```python
#!/usr/bin/env python3
MOD = 1 << 32
A = 1664525
C = 1013904223

def keystream(seed, length):
    state = seed & 0xFFFFF
    out = bytearray()
    for _ in range(length):
        state = (A * state + C) % MOD
        out.append((state >> 24) & 0xFF)
    return bytes(out)

def xor_bytes(left, right):
    return bytes(a ^ b for a, b in zip(left, right))

def encrypt(message: bytes, facility_seed: int) -> bytes:
    return xor_bytes(message, keystream(facility_seed, len(message)))
```

## Analysis

The encryption is a stream cipher: the plaintext is XORed with a keystream
generated by a **Linear Congruential Generator (LCG)**:

```
state_{i+1} = (A * state_i + C) mod 2^32
keystream_i = (state_{i+1} >> 24) & 0xFF
```

with the well-known constants `A = 1664525`, `C = 1013904223` (the classic
*Numerical Recipes* LCG). The constants and the recurrence are public
information, so none of that is secret. The only "secret" is the seed used
to initialize `state`.

### The bug

Look closely at this line:

```python
state = seed & 0xFFFFF
```

The seed is masked with `0xFFFFF` (5 hex digits = **20 bits**), even though
`state` itself is a full 32-bit value. This means no matter what
`facility_seed` was actually chosen, only

```
2^20 = 1,048,576
```

distinct starting states are possible. That is a *tiny* keyspace — fully
brute-forceable in well under a second on a laptop.

### Attack plan

1. Recreate the `keystream()` function locally (constants are known/public).
2. Iterate `seed` from `0` to `2^20 - 1`.
3. For each candidate seed, generate a keystream of the same length as the
   ciphertext and XOR it with the ciphertext.
4. Check whether the resulting plaintext contains the known flag prefix
   `grodno` (or is otherwise printable/sensible text).
5. Once found, print the plaintext and extract the flag.

Because XOR is its own inverse, decryption uses the exact same function as
encryption:

```
plaintext = ciphertext XOR keystream(seed, len(ciphertext))
```

## Solve Script

```python
#!/usr/bin/env python3
"""
Solver for "Aperture Science: Stream Calibration"
Vulnerability: seed is masked with `& 0xFFFFF` (only 2^20 = 1,048,576
possible states), so the LCG keystream can be brute-forced entirely.
"""

MOD = 1 << 32
A = 1664525
C = 1013904223

CIPHERTEXT_HEX = (
    "1b89ad17b196d415f519f17c9bfa709ac9a7a71605c6d91a7f08fcbb08c2833298388913e8"
    "43bb0b8bd7bca262207fd861db5440715da4e2916b6245e450df243c6398e0c27fe8d83044"
    "b2a4100b83783e65fd27969f9a0adef8decede83339001f71e7fc83a3f7c415c0362d61a28"
    "d8d9e83970c840093a0fb6f0a1"
)

NEEDLE = b"grodno"  # known flag prefix to detect the correct seed


def keystream(seed: int, length: int) -> bytes:
    state = seed & 0xFFFFF
    out = bytearray()
    for _ in range(length):
        state = (A * state + C) % MOD
        out.append((state >> 24) & 0xFF)
    return bytes(out)


def xor_bytes(left: bytes, right: bytes) -> bytes:
    return bytes(a ^ b for a, b in zip(left, right))


def main():
    ct = bytes.fromhex(CIPHERTEXT_HEX)

    for seed in range(1 << 20):  # brute force all 2^20 possible seeds
        pt = xor_bytes(ct, keystream(seed, len(ct)))
        if NEEDLE in pt:
            print(f"[+] Found seed: {seed}")
            print(f"[+] Plaintext:\n{pt.decode(errors='replace')}")

            start = pt.find(b"grodno{")
            end = pt.find(b"}", start)
            if start != -1 and end != -1:
                print(f"[+] FLAG: {pt[start:end+1].decode()}")
            return

    print("[-] No matching seed found in range.")


if __name__ == "__main__":
    main()
```
